Capstone

AI-Enabled SOC Engine

This capstone project focuses on automating triage for malicious-site alerts inside a SOC workflow. Our system pulls alerts from Jira, extracts domains and URLs, enriches them with VirusTotal, applies classification logic, and posts a structured triage summary back to the original ticket. The goal is to reduce repetitive analyst work while improving response speed, consistency, and explainability.

Problem and Goal

  • Reduce manual investigation time for repetitive malsite alerts.
  • Standardize triage so alerts are handled more consistently across cases.
  • Create explainable outputs that analysts can trust and act on quickly.
  • Build an extensible workflow that can support additional verdict types and enrichments over time.

System and Tools

  • Python backend workflow integrating Jira and VirusTotal APIs.
  • Indicator extraction for domains and URLs from incoming alert metadata.
  • Automated classification and structured summary generation for analyst review.
  • MCP-style service architecture designed for iterative refinement and future expansion.

Milestones Completed

  • Milestone 1: completed project setup, planning documents, architecture design, and access validation.
  • Milestone 2: built the core Jira retrieval, VirusTotal enrichment, and indicator extraction pipeline.
  • Milestone 3: reached MVP with classification logic, triage summary generation, and Jira auto-posting.
  • Current work: improving testing, logging, error handling, thresholds, and feature coverage.

My Contributions

  • Contributed to backend system design and API integration for the end-to-end triage workflow.
  • Focused on making the system more reliable through better logging, maintainability, and error handling.
  • Helped shape the project around a practical MVP instead of an overbuilt prototype.
  • Strengthened my ability to build software around a real operational workflow rather than a classroom-only demo.

Why It Matters

The value of this project is not just in automating a single task. It shows how engineering can turn a repetitive security workflow into a faster, more structured, and more scalable process. That made the project a strong example of the kind of work I want to keep doing: building systems that solve real team problems and make technical decisions easier for users downstream.
